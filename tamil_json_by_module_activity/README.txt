Tamil JSON split by Module and Activity
=======================================

Total records: 1178
Module values restored from companion workbook using Master Sequence: 565
Module + Activity JSON files: 84

Each JSON file is an array of original record objects. The original fields and Tamil Unicode text are retained.
Missing Module values were filled using matching Master Sequence values from the workbook. Existing Module values were checked against the workbook and matched.
For grouping only, leading/trailing whitespace in Activity is ignored; Activity strings in the records are not changed.
index.json lists each module/activity file and its record count.
